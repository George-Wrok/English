# TalkPulse - 英文口說隨身教練 ⚡

專為職場轉換與日常溝通打造的 100% 零費用隨身 AI 英文口說練習 PWA Web App。

## 🛠 更新日誌 (Update Log)

### [2026-08-26]
- **功能新增**：首頁頂部推出「📊 口說學習成就儀表板」，即時記錄並呈現「⏱️ 今日練習時間」、「⏳ 總練習時間」、「🔥 連續練習天數」，全自動累計、本機 `localStorage` 永久保存。
- **功能優化**：達成「100% 單字點選繁中即時釋義」，擴充完整日常/職場基礎辭庫並整合極速線上查詞與本機 `localStorage` 快取，徹底解決部分生詞顯示「單字發音已朗讀」問題，做到點擊任何單字 0 秒秒出中文。
- **功能優化**：麥克風全面升級為「手動啟停控制」，錄音不會因短暫停頓或句子達標而自動中斷，必須由使用者再次點擊麥克風才停止收音並送出/結算。
- **功能優化**：單字點選浮動工具優化，點擊任何英文單字時，自動朗讀發音並在下方即時顯示該單字的「繁體中文意思（釋義）」，移除冗餘的慢速按鈕。
- **功能新增**：點選救命句時新增「自動先朗讀示範」功能，系統會先播放一次使用者選定的救命句發音，唸完後 AI 角色再順暢接話回覆，營造逼真的雙向對答節奏。
- **功能新增**：點選「💡 救命句推薦」或採用「🇹🇼 中文求助」回答時，使用者氣泡下方自動附加「🌐 翻譯」、「🔊 重聽」、「🐢 慢速」、「🎯 跟讀檢測」4 大輔助工具列；使用者自己開口口說的句子則維持簡潔純文字。
- **功能新增**：首頁推出「📰 每日 3 分鐘時事快報（Daily News Bites）」，AI 自動整理今日 3 則全球時事（科技/國際/生活），每則控制為 50~60 字黃金口說長度，支援單字點讀、慢速朗讀、逐字跟讀檢測、與 AI 新聞觀點對話。
- **功能新增**：實作「單字即點即唸（Tap-to-Pronounce）」與「浮動發音小工具」，所有 AI 訊息、建議句、求助翻譯內的任何英文單字輕點即秒聽標準發音與慢速發音。
- **功能新增**：實作「語音即時問發音攔截機制（Voice Pronunciation Intercept）」，對話時說出「...怎麼唸？」或「How to pronounce...」，AI 會立即中斷常規對答並插話示範單字發音。
- **功能新增**：實作「🎯 逐字跟讀與發音糾錯（Shadowing Practice）」，即時辨識開口跟讀句子，單字發音正確自動亮綠光，支援單字點讀與整句慢速聽。
- **功能新增**：實作「🇹🇼 說中文幫我想英文（中文求助）」功能，當使用者不知如何表達時，可直接說中文或輸入中文，AI 會結合當前對話情境生成 3 種風格的道地英文建議句，並提供「正常/慢速發音」與「一鍵採用回覆」。
- **功能新增**：在所有 AI 對話氣泡與建議句卡片旁新增「🐢 慢速」朗讀按鈕，支援慢速語速清晰發音。
